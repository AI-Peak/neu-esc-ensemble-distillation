# NEU-ESC Feedback Workspace

## Context

An operator reads and checks student feedback on a laptop at a desk in daylight. The interface is a dense, readable working tool. White surfaces preserve contrast; cobalt identifies the next action and current selection. Research is a secondary navigation destination.

## Tokens

- Background: pure white, `oklch(1 0 0)`.
- Brand anchor: cobalt, `oklch(0.550 0.149 250)`; hover `oklch(.47 .145 250)`.
- Demo Theme (Layout 2): Deep teal `#0f766e` / `#0d9488`, slate neutrals, soft teal tints for active cards and progress indicators.
- Ink: `oklch(.25 .022 250)`; supporting text `oklch(.46 .025 250)`.
- Neutral surface: `oklch(.977 .006 250)`; border `oklch(.88 .013 250)`.
- System font: Segoe UI, system-ui. Font Be Vietnam Pro (`/fonts/be-vietnam-pro-*.ttf`) bundled locally for optimal Vietnamese typography in the Sentence Demo without external Google Fonts requests. Base 14px / 1.5; table 12–13px; headings 16–25px. All support Vietnamese without remote font requests.
- Sentence Demo overrides the workspace scale: body 16–18px, labels/captions at least 14px, including shared sensitivity/attention components inside the demo. Preserve the approved teal layout.
- Corners: controls 5–6px, dialogs 10px. Dividers organize the workspace rather than nested cards.

## Interaction

Top-level navigation: default route `#/demo` for the single sentence analysis, datasets `#/`, new dataset `#/new`, research `#/research`, status/help `#/help`.
The Sentence Demo (`#/demo`) implements the clean 2026-11-12 redesigned interface in a vertical flow:
Internal presentation flag: `DEMO_EXTENDED_SECTIONS_ENABLED` in `apps/web/src/demoConfig.ts` defaults to `false`. The overview, word network and evidence sections below are preserved as optional features, together with their header links. They render and fetch data only when the flag is `true`; there is no UI switch. Change the source flag and rebuild to restore them. The primary analysis, attribution and sensitivity flow stays available.
- **Header**: Brand title `NEU–ESC`, navigation links (`Phân tích câu`, `Câu vừa phân tích`, `Mạng từ`), with no profile selector or replacement badge. Demo is fixed to NEU (`neu-v1`, four sentiments, ten topics); missing or unavailable NEU disables analysis with an explicit error. UIT remains in workspace/backend.
- **Input row**: Full-width textarea with character counter, "Phân tích" primary button, and "Xóa" button. A single 7px teal progress track sits below the actions. Request/job states drive indeterminate prediction progress; validated nonnegative integer attribution counters with total >0 drive determinate contribution progress. Invalid/missing counters stay indeterminate; complete counters or pending payload validation read “Đang hoàn tất kết quả…”. Only validated results complete the step. Cancel targets the current task, including a pending submit; editing/clearing/new generations discard old progress. Use a polite status region, named progressbar, aria-valuenow only for real progress and reduced-motion support.
- **Local AI Prediction**: Renders immediately when the quick-analysis job finishes. Shows sentiment and topic in two distinct groups. Each label and its lower-emphasis softmax score sit 10px apart on the baseline; groups stack when space is insufficient. “Phân bố điểm cảm xúc” labels the sentiment stack, with the exact uncalibrated-score notice preserved. Ten NEU topics retain API order and expand/collapse. Topic rows use a 180–200px label column, flexible 7px track and 60px score, with 12px gaps; narrow panes put the full-width track below label/score. Bars map directly to 0–100%, including zero width at zero.
- **Word Attribution & Contributions (P0)**: Full-width left-aligned highlighted feedback precedes a compact list, replacing the merged four-column table. Two balanced columns on desktop read down the left column then down the right, matching DOM/tab order; one column below 760px. Each 36–40px row places phrase, flexible meter and signed value together at 16px. Long phrases grow naturally; touch targets are at least 44px and captions at least 14px. Default top six absolute contributions display in sentence order; the remaining count and signed sum accompany “Xem tất cả N cụm từ”. Collapse controls remain above and below an expanded list; collapsing clears a selection that would become hidden. No nested scrolling or fixed list height. All meters share the full snapshot maximum magnitude; the footer always shows the full signed total in percentage points. “Cách tính tổng” retains baseline + total = target, rounding, residual, method and limitations. Neutral/Toxic label_score retains blue/amber increase/decrease semantics and its target label; polarity retains positive/negative leaning. Two-way phrase/highlight selection and the contribution donut are preserved.
- **Latest Sentence Overview (P1)**: Informational SVG contribution donut using all original groups from the same validated attribution snapshot as the contribution list. Positive/negative contribution mass is normalized to100%; the center reads “Đóng góp từ ngữ”, with two textual percentage legend rows and a short limitation note. Polarity uses green/red “Nghiêng tích cực/tiêu cực”; label_score uses blue/brown “Tăng/Giảm điểm [profile label]”. No count/net sentiment KPI, interactive segments or evidence filter on this chart. Loading/error/unsupported/zero contributions have explicit states; summary loading never gates the donut. Topic attention ranking retains negative counts, proportions, small-sample warnings and evidence filtering on the latest quick-analysis dataset/run. One input remains a single text item even when it has several sentences, without history accumulation or a dataset selector.
- **Word Co-occurrence Network (P2)**: SVG graph canvas displaying terms from that same latest sentence (window=5 original segmented-token positions before stopword filtering, distance <=4) connected by co-occurrence edges, connected components groups with consistent color swatches, sidebar insights, and drill-down to matching feedback items. Editing or clearing removes the previous analysis scope.
- **Evidence Drill-Down**: Interactive cards displaying matching feedback rows with active filter chips, sentiment/topic badges, and pagination.

Dataset work uses tabs, shared filters, chart buttons, a paginated server table, and a native dialog aligned to the right for detail. Hash routes keep deep links usable with a static server. Filters persist per dataset for the browser session.

Every chart button applies the same filter model as list, summary and export. Denominators explicitly count rows with a label. AI predictions, reference labels, and human reviews have separate sections and export fields. Reviews are independent for sentiment/topic. Text edits create revisions; historical results warn when stale.

Native form controls, visible keyboard focus, dialog focus management, semantic headings and live status messages support keyboard and assistive technology. At 650px, the item table becomes a stacked list and the detail dialog fills the screen. Reduced motion disables transitions and panel entry. Empty states describe the next action; missing models never produce synthetic predictions.

## Validation

`npm run build` passes strict TypeScript and the Vite production build. Dependencies are pinned with a package lock; `npm audit` reports zero vulnerabilities (Vite 7.3.7).

Playwright checked the complete CSV/import → analysis → chart filtering → independent review → snapshot export → API restart flow at 1440px and import/persistence/missing-model behavior at 390px, with no page errors or horizontal body overflow. Additional browser assertions covered AI confirmation, review undo, double-task save-next, text revisions and stale warnings, disabled restoration from older input revisions, and quick-analysis polling/add-to-dataset. Screenshots were inspected. These integration runs explicitly use a test-only predictor double, not a production model or benchmark claim.

Compact demo acceptance (2026-11-12): built with `npm run build` and visually inspected Chromium screenshots at 1366×768, 1440×900 and 390px, device scale 1 / zoom 100%. The 21-group UI fixture measures approximately 646px for the full expanded word section at both laptop widths, without clipping or nested scrolling. Longer feedback and long Vietnamese labels wrap naturally; touch targets, selection, stable meters/totals, missing NEU, queued/loading/running states, real/invalid progress, validation, cancellation, retries and stale responses have browser coverage in `tests/e2e/test_demo_compact.py` and the existing demo/attribution suites. The fixture verifies layout, not model quality. Separately, an isolated runtime with the verified local NEU bundle passed live prediction/attribution browser acceptance, including both attribution targets, truncation and expired-source errors. Evidence and detailed results are in `test-results/demo-compact-20261112/`.

Network/model errors remain visible and actionable; retries never replace real inference with fabricated output. Missing-model technical paths live inside collapsed details; empty summaries show an explanatory state until labels exist.
